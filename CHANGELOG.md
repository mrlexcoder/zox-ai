# Changelog

All notable changes to Zox AI will be documented in this file.

## [1.1.0] - 2026-05-05

### Added
- 🎨 **ASCII Art Banner** - Beautiful startup banner in console
- 📋 **Clipboard Operations** - Copy, paste, and manage clipboard
- 🔔 **Windows Notifications** - Native notification support
- 📜 **Command History** - Track and review past commands
- ⭐ **Favorites System** - Save frequently used commands
- ⚙️ **Settings Dialog** - GUI for configuring Zox AI
- 📊 **Usage Statistics** - Track command success rates
- 🎯 **Enhanced UI** - Settings and history buttons in main window

### Improved
- Better error handling and user feedback
- Enhanced logging system
- More responsive GUI
- Improved command tracking

### Technical
- Added `utils/` module for utilities
- Added `ClipboardController` for clipboard operations
- Added `NotificationController` for Windows notifications
- Added `HistoryManager` for command tracking
- Added `SettingsDialog` for configuration GUI
- Updated dependencies (pyperclip, win10toast)

## [1.0.0] - 2026-05-05

### Initial Release
- 🎤 Voice input with faster-whisper

- 🖥️ Full computer control

- 📊 System monitoring
- 🌐 Browser automation
